## 最终事实（全部经独立复算）

1. **y 是正确的**。raw_data/test.csv 作为整张表按 label 排序（每行内部自洽），
   `build_features_npy.py` / `build_features.py` 均按文件顺序追加特征与标签
   ⇒ y[i] = 第 i 行指标通道所属样本的真实标签。
   验证：X 第 i 行 MA 通道 vs test.csv 第 i 行源数据 MA 窗口，相关 = **1.0000**（300/300 >0.99）。
2. **9 个基础价格通道（0-8）乱序**。`preprocess.py` 按 code 分组重排样本切窗口（其自带的 X/y 本是对齐的），
   `build_features_npy.py` 按位置直接拼接指标特征，未把基础通道顺序对回文件序
   ⇒ 同一行：基础通道来自样本 A（code 组序），指标/市场通道与 y 来自样本 B（文件序）。
   验证：用本行 close 通道自算 MA/ROC 与指标通道 MA/ROC 相关 ≈ **0**（同源应 ≈1）。
3. **模型评估真实有效**。(指标通道, y) 是真实配对：TCN 50.24%、新 GRU 59.5% 均为真实技能
   （GRU 恰好丢弃 open/high/close/volume 四个乱序基础通道，训练数据更干净，故更高——反向印证病因）。
   早前"对指纹真值仅 32.6%"的说法，是把预测错配到基础通道样本 A 的标签上，无意义。
4. **原回测（恒等映射）配对正确**：预测的信息载体是指标通道，指标通道 ↔ test.csv 第 i 行（corr=1.0）。
   引擎复算（账目/撮合/时点）全部 PASS ⇒ **TCN 主策略 +105.66%、GRU 无风控 +202.59% 等结果有效**。
   恢复位置：`task3_2024_2025_results/`、`task3_new_gru_results/`、两份绩效报告（根目录）。
